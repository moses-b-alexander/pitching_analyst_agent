# Live Starting Pitching Analyst — Agent

The standalone agent implementation of the [Live Starting Pitching Analyst](https://github.com/moses-b-alexander/live-pitching-analyst-chatgpt-plugin).

The plugin is a skills-only package that relies on the host's browsing tools. This repository is the **separate agent implementation** that the plugin README mentions: deterministic data fetching and stat lines, with an open-weight model for interpretation.

> **Track the matchup; analyze the pitcher.**

The goal is the same: **make watching starting pitching more interesting without making you stare at another dashboard.**

---

## Relationship to the plugin

Both projects implement one behavioral specification:

```text
skills/
└── live-starting-pitching-analyst/
    └── SKILL.md
```

`SKILL.md` is mirrored from the plugin repository and remains the canonical behavior contract. The agent adds what a chat-only skill cannot guarantee:

* a real live data feed, so it does not depend on the host's browsing,
* autonomous starter-exit detection and 10-minute reconciliation polling,
* stat lines computed in code, never generated by the model,
* a persistent observation and hypothesis ledger that survives restarts,
* numerical tests executed deterministically and interpreted by the model.

---

## The three products

The products are the same as in the plugin:

1. **Stat Line** (ground truth). Composed entirely in code.

   ```text
   Line: 17 P · 11S/6B | 1 R · 3 H | 2 K · 1 BB
   Mix: 4S 8 (47%) · SI 3 (18%) · FC 2 (12%) · CU 4 (24%)
   Hits: S8 · S7 · D9
   ```

2. **Summary**: an evolving baseball model, with a small set of persistent theses.
3. **Analyst**: turns an observation into a statistical question, so a casual remark becomes a testable hypothesis.

## Architecture

```text
MLB Stats API (live)  ·  Baseball Savant (season baselines)
    ↓
sources/        fetch + normalize to Savant conventions
    ↓
analytics/      inning windows · line / mix / hits · stat tests     ← all numbers come from here
compositor.py   the three fixed stat lines
    ↓
llm/            one OpenAI-compatible endpoint (local Ollama by default)
    ↓
agent.py        terminal
```

Nothing about the game is stored: the MLB feed is cumulative, so a restart refetches it. SQLite holds only the observations you type, indexed by team and starting pitcher, and they are cleared on command or 24 hours after the game ends.

The stat lines work with no model configured.

* Product-owner decisions and current scope: [`docs/decisions.md`](docs/decisions.md)
* Original design handoff (broader than what is built): [`docs/architecture.md`](docs/architecture.md)

## Quick start

```bash
pip install -e ".[dev]"
python scripts/fetch_fixtures.py   # test data (MLB-licensed; not committed)
pytest
python agent.py --game <gamePk>            # follow a game live
python agent.py --game <gamePk> --replay   # replay a finished game offline, play by play
python agent.py --game <gamePk> --once     # one snapshot of both starters' lines
```

For model interpretation (optional; stat lines work without it), install [Ollama](https://ollama.com) and run:

```bash
ollama pull qwen3:8b
ollama create qwen3:8b-8k -f ollama/Modelfile   # same weights, 8,192-token context
```

## Status

Early development.

```text
Done   MLB live feed -> pitches / plate appearances / box lines (matches box score and Savant)
Done   Three deterministic stat lines; inning windows; exit completeness check
Done   Observation store (by team / starter), clear command, 24 h auto-clear
Done   Polling loop: half-inning capsules (half-inning lag), starter-exit detection and verified final line,
       backoff on feed failure, offline replay

       classified, and answered; /status, /obs, /clear, /quit
Done   Savant season baseline per starter (re-pulled each game, cached fallback) + pregame lines
```
